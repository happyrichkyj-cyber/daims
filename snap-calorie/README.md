# 칼로리 스냅

음식 사진을 찍으면 항목별 칼로리와 탄단지를 추정해주는 모바일 웹앱.
PC에서 서버를 켜두고 같은 와이파이의 폰 브라우저로 접속해 쓴다.

## 시작하기

### 1. API 키 넣기

`.env.example`을 복사해 `.env`로 이름을 바꾸고 키를 채운다.
키는 https://console.anthropic.com/settings/keys 에서 발급.

```
ANTHROPIC_API_KEY=sk-ant-...
```

### 2. 설치 (최초 1회)

```bash
npm install
```

### 3. 실행

```bash
npm start
```

터미널에 두 개의 주소가 뜬다.

- `http://localhost:3000` — PC 브라우저
- `http://192.168.x.x:3000` — 폰 브라우저 (PC와 같은 와이파이에 연결되어 있어야 함)

폰에서 접속한 뒤 **공유 → 홈 화면에 추가**를 하면 앱 아이콘처럼 쓸 수 있다.

## 쓰는 법

화면은 **등록 · 자주 · 오늘** 세 탭이다.
등록 탭은 *한 끼*를 계산하고, 오늘 탭은 *하루*를 합산하며, 자주 탭은 저장해 둔 걸 재사용한다.

### 등록 탭 — 한 끼 계산

사진, 메모, 또는 둘 다로 계산한다.

1. **사진 넣기** — 세 가지 방법
   - **사진 찍기** — PC에서는 웹캠이 바로 켜지고, 폰에서는 카메라 앱이 열린다
   - **파일에서** — 탐색기에서 여러 장 한 번에 고를 수 있다
   - **드래그앤드롭 / Ctrl+V** — 파일을 끌어다 놓거나 캡처를 붙여넣는다
2. **여러 각도로 더 올린다** (최대 4장). 여러 장은 각각 더해지는 게 아니라
   *같은 한 끼*로 묶여 계산된다. 한 장에서 가려진 그릇이 다른 장에서 보이면 그만큼 정확해진다.
3. **메모** (선택) — "밥은 반만", "둘이 나눠 먹어요". 자주 쓰는 문구는 버튼으로 넣는다.
   **사진 없이 메모만으로도 계산된다** — "당근 50g", "아메리카노 톨" 처럼 적으면 된다.
4. **칼로리 계산** → 결과에서 **먹은 양**(0.5 / 1 / 1.5 / 2 / 3인분)과 **끼니**를 고르고 담는다.
   양은 기본 1인분이고, 바꾸면 총합·항목·그램이 모두 즉시 다시 계산된다.
   끼니는 지금 시각을 보고 미리 골라져 있다.
5. **⭐ 자주 먹는 것에 저장** — 매일 먹는 것은 한 번만 계산해 두고 재사용한다.

앱 하단 **더 정확하게 찍는 법**에 요령이 정리돼 있다.

### 자주 탭 — 재사용

저장해 둔 항목을 사진 없이 바로 담는다.
항상 **1인분 기준**으로 저장되므로, 담을 때 양만 골라주면 된다.
위에서 끼니를 먼저 고르고 각 항목의 **담기**를 누른다.

### 오늘 탭 — 하루 합산

하루 총 칼로리와 목표 대비 남은 양, 그리고 아침·점심·저녁·간식별 소계와 항목이 보인다.
목표 칼로리는 직접 고칠 수 있고, 각 항목은 × 로 지운다.

## 알아둘 것

- **추정치다.** 사진만으로는 기름 양, 밥 안에 파묻힌 재료, 국물을 얼마나 먹는지 알 수 없다.
  신뢰도가 `낮음`으로 뜨면 숫자를 그대로 믿지 말 것.
- **사진은 저장되지 않는다.** 분석을 위해 Anthropic API로 한 번 전송될 뿐, 서버 디스크에 남지 않는다.
- **기록은 브라우저에만 남는다.** localStorage를 쓰므로 폰과 PC의 기록은 서로 분리되어 있고,
  브라우저 데이터를 지우면 함께 사라진다.
- **비용** — 사진 1장당 대략 1,500~5,000 입력 토큰 + 500~1,500 출력 토큰이 든다.
  사용량은 https://console.anthropic.com/settings/usage 에서 확인할 수 있다.

## 손볼 만한 곳

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 더 정확하게 (느리고 비쌈) | `server.mjs`의 `effort: 'low'` → `'medium'` 또는 `'high'` |
| 더 싸게 | `.env`에 `MODEL=claude-sonnet-5` 추가 |
| 추정 기준 바꾸기 | `server.mjs`의 `SYSTEM` 프롬프트 |
| 결과 항목 추가 (나트륨, 당류 등) | `server.mjs`의 `SCHEMA` + `public/index.html`의 `showResult()` |
| 화질 올리기 | `public/index.html`의 `shrink(file, 1024, 0.82)` 숫자 |

## Vercel에 올리기

폰에서 매일 쓰려면 이쪽이 맞다. PC를 꺼도 되고, 주소가 고정되고, HTTPS라 아이폰 브라우저에서
카메라가 바로 열린다.

### 1. 저장소 붙이기 (즐겨찾기를 기기 사이에 맞추려면 필요)

Vercel 대시보드 → **Storage** → Redis 계열(Upstash 등)을 프로젝트에 연결한다.
연결하면 `KV_REST_API_URL` / `KV_REST_API_TOKEN` 환경변수가 자동으로 꽂힌다.
(`UPSTASH_REDIS_REST_URL` / `..._TOKEN` 이름으로 꽂혀도 그대로 동작한다.)

붙이지 않아도 앱은 돌아간다. 대신 즐겨찾기와 기록이 **기기마다 따로** 남는다.

### 2. 환경변수 세 개

| 이름 | 값 |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic 콘솔에서 발급한 키 |
| `ACCESS_CODE` | 아래 설명 참고 |
| `MODEL` | (선택) 기본값 `claude-opus-5` |

### 3. 배포

```bash
npx vercel
```

브라우저로 로그인한 뒤 안내를 따르면 된다. 배포 후 `npx vercel --prod` 로 운영 주소에 올린다.

> **첫 배포에서 화면이 안 뜨면** `vercel.json`의 `outputDirectory`를 확인한다.
> 정적 파일은 `public/`에 있고 함수는 `api/`에 있다는 전제다.

## 접속 코드 (인증)

회원가입은 없다. **접속 코드 하나가 곧 인증이자 내 서랍의 열쇠다.**

- 폰과 PC에 같은 코드를 넣으면 같은 즐겨찾기·기록을 본다
- 코드는 쉼표로 여러 개 둘 수 있고, **코드마다 서랍이 따로** 생긴다
  (`ACCESS_CODE=snap-6986da-d3dfc5,wife-1a2b3c-4d5e6f`)
- 코드를 비워 두면 잠금이 풀린다 — **로컬에서만 그렇게 쓴다**

> ⚠️ 공개 주소는 누구나 열 수 있고, 계산 한 번마다 내 API 크레딧이 나간다.
> `1234` 같은 코드는 금방 뚫린다. **12자 이상 무작위**로 쓸 것.
> 예: `snap-6986da-d3dfc5`

코드는 계산 API(`/api/analyze`)와 동기화 API(`/api/data`)를 함께 잠근다.
화면(HTML/CSS/JS)은 잠기지 않지만, 코드 없이는 아무것도 계산하거나 읽지 못한다.

## 디자인

모바일 우선으로, [getdesign.kr](https://getdesign.kr) 카탈로그의 토스 `design.md`를 디자인 브리프로 삼아
시각 언어만 차용했다 (토스의 서비스·브랜드와는 무관하다).

가져온 것과 지킨 규칙:

- **색** — OKLCH 원본값 그대로. cool-blue 계열 중성색 위에 브랜드 블루 하나.
  **화면당 강조색은 하나**라서 파랑은 primary CTA에만 쓰고, 나머지는 회색 위계로 푼다.
- **타이포** — Pretendard(토스 자체 서체의 공식 권장 대체). 본문 15px / 1.5,
  숫자는 전부 `tabular-nums`라 자릿수가 흔들리지 않는다.
- **형태** — 라운드 사다리(4·8·12·14·16·20·24·32·999), 1px 헤어라인 보더, 평면 표면.
  버튼은 크기와 라운드가 짝(XL 56/16 · L 48/14 · M 40/12 · S 32/10).
- **모션** — 120 / 200 / 320ms 안에서만. 바운스·패럴랙스 없음.
- **로딩** — 스켈레톤 셰이머 대신 3-dot.
- **카피** — 해요체. 모델이 만드는 문구도 해요체로 나오게 프롬프트에 못 박았다.
- **이모지 금지** — 버튼·라벨의 이모지는 전부 24px 그리드 / 1.5px stroke 아이콘으로 교체했다.

다크 모드 alias는 원문에 공개돼 있지 않아 `app.css`의 다크 팔레트는 내가 추론한 값이고,
파일 주석에 그렇게 표시해 두었다.

디자인 브리프를 가져온 스킬은 `.agents/skills/use-design-md`에 설치돼 있다.

## 구조

로컬 서버와 Vercel Function이 **같은 핸들러**를 쓴다. 로직은 한 군데에만 있다.

```
api/analyze.js       칼로리 계산 엔드포인트
api/data.js          즐겨찾기·기록 동기화 엔드포인트
lib/analyze.mjs      프롬프트·스키마·Claude 호출
lib/store.mjs        저장소 (Vercel은 Redis REST, 로컬은 .data/store.json)
lib/http.mjs         접속 코드 검사, 본문 읽기, 응답
server.mjs           로컬 개발 서버 (위 핸들러를 그대로 호출)
public/index.html    마크업 + 아이콘 스프라이트
public/app.css       디자인 토큰과 컴포넌트
public/app.js        화면 로직 + 동기화
vercel.json          정적 폴더 지정, 함수 실행시간 60초
.env                 로컬 환경변수 (git에 올리지 말 것)
```

동기화는 **로컬이 원본**이다. 브라우저 저장소에 먼저 쓰고 서버로 밀어 넣는다.
서버가 없거나 실패해도 앱은 그대로 돌아가고, 다음 변경 때 다시 올라간다.
